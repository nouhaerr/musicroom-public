# Sonora LinkedIn presentation

This folder contains an eight-slide portrait carousel about Sonora, a mobile-first collaborative music project built by a team. The web client is presented as a companion experience.

- `sonora-linkedin.pdf` is ready to share as a LinkedIn document carousel.
- `sonora-linkedin.pptx` is the editable PowerPoint source.
- `linkedin-post.md` is a draft caption that describes the team project and my contribution accurately.

The carousel uses mobile app screenshots and web interface captures from local development builds. Any visible accounts, playlists, and music are demo data. Web captures come from the `sonora_web` folder on the Desktop. It summarizes the project architecture and the GitHub pull request and CI workflow; CI runs automated checks and does not deploy the apps.
