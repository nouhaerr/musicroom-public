I’m sharing Sonora, a mobile-first collaborative music app built as a team project for iOS and Android, with a companion web client.

My main contribution focused on authentication and social features across the mobile app, companion web client, and API: account verification and password reset, Google/Facebook sign-in and account linking, privacy-aware profiles, friend requests, device sessions, playlist invitations, and per-device control delegation. I also worked on the project workflow with feature branches, pull requests, reviews, and GitHub Actions CI checks.

The project uses Expo/React Native as its primary client, plus React for web, NestJS, TypeScript, Prisma, PostgreSQL, and Socket.IO. The carousel includes mobile app screens, web captures from a local development build, and a short overview of how the team used pull requests and CI to validate changes.

This was collaborative work, and the rooms, music catalog, playlists, and real-time queue features were developed with my teammate.
