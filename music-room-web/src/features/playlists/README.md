# Playlists

The list (`/playlists`), Create a playlist (`/playlists/new`) and a playlist (`/playlists/:playlistId`): live songs,
drag and drop, add and remove, the invitation, and the radio. The owner's Access & people page is in `features/access`.

`playlists.ts` is the calls of the mobile app; the pages use the shared pieces of `features/rooms`.
