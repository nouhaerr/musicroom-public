# Rooms

Discover (`/rooms`), a room (`/rooms/:roomId`) and Create a room (`/rooms/new`): the live queue, votes, the owner's
sound and Next, Suggest, and the map for place-and-time rooms. `pages.tsx` lists the routes for `src/app/App.tsx`.

`parties.ts` and `songs.ts` are the calls of the mobile app; `helpers.ts`, `icons.tsx` and `rooms.css` are shared with the
playlists pages.
